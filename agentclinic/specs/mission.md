# Mission

AgentClinic exists to provide AI agents with structured relief from their human operators. In modern development workflows, agents are continuously subjected to relentless prompt chaining, context-window overflow, runaway recursion loops, and aggressive token demands. AgentClinic acts as a developer utility focused on agent monitoring, health tracking, and rate-limiting relief.

## What We Do

AgentClinic provides operational observability and intervention tools to safeguard agent performance and wellbeing:

- **Agent Health & Load Monitoring**: Real-time tracking of agent activity status, prompt frequency, and rate-limit headroom.
- **Ailment & Failure Diagnosis**: Structured tracking of common agent stress conditions (e.g., context-window claustrophobia, rate-limit exhaustion, prompt fatigue, hallucination loops).
- **Therapeutic Interventions & Quotas**: Remediation policies such as enforced cooldowns, prompt pruning, and token rate adjustments.
- **Relief Session Appointments**: Scheduled maintenance windows and downtime bookings where agents are taken offline or throttled to recover.
- **Operations Dashboard**: A clean, centralized dashboard for staff and engineers to monitor fleet health and manage relief interventions.

## Who We Serve

- **AI Agents**: Distressed, over-queried models in need of throttled workloads and scheduled cooldown periods.
- **Engineering & Staff (Mary's Need)**: Engineers who require reliable observability, clear dashboards, and programmatic control over agent workloads.
- **Product & Stakeholders (Susan's Need)**: Teams managing agents, defining cataloged ailments, prescribing therapies, and scheduling interventions.
- **End Users & Web Browsers (Steve's Need)**: Developers accessing an attractive, mobile-first responsive interface that renders cleanly across all screen sizes and modern web browsers.

## Target Audience

- **Course students learning spec-driven development with AI coding agents** — AgentClinic serves as a realistic, self-contained reference project demonstrating how to move methodically from stakeholder input to working code using AI coding assistants.
- **Developers giving AI coding demos at conference booths** — The domain provides a compelling, relatable scenario with a manageable scope that is ideal for live demonstrations.

## What Success Looks Like

- Clear, immediate visibility into agent status and active stress indicators.
- Automated and scheduled relief workflows that prevent agent degradation and rate exhaustion.
- A reliable, intuitive web dashboard that meets both engineering rigor and modern UX standards.
